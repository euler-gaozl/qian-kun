# 乾坤期货策略 MCP 服务器

这是一个Model Context Protocol (MCP)服务器,用于查询乾坤期货交易系统的实时策略信号。

## 功能特性

- ✅ **批量查询**: 一次性查询多个品种/合约/周期组合
- ✅ **多轮对话**: 支持在LLM对话中进行持续查询
- ✅ **智能解析**: 自动将自然语言转换为API调用
- ✅ **格式化展示**: 结构化展示策略信号和建议

## 团队协作安装 🤝

### 一键安装(推荐)

团队成员克隆项目后,使用自动安装脚本:

```bash
cd mcp-server
./install-mcp.sh
```

脚本会自动:
- ✅ 检测Node.js环境
- ✅ 安装依赖
- ✅ 编译MCP服务器
- ✅ 自动获取当前项目路径(不需要硬编码)
- ✅ 配置到Kilo或Claude Desktop
- ✅ 支持自定义API地址

### 安装选项

运行脚本后会提示选择:
1. 配置到Kilo (VSCode插件)
2. 配置到Claude Desktop
3. 两个都配置
4. 只显示配置信息(手动配置)

### 自定义API地址

脚本会询问后端API地址,支持:
- 本地: `http://localhost:8000` (默认)
- 远程: `http://your-server:8000`
- 其他端口: `http://localhost:9000`

## 支持的品种

- **黑色系**: rb(螺纹钢), i(铁矿石), hc(热卷)
- **股指**: IC(中证500), IF(沪深300), IH(上证50)
- 等等...

## 支持的周期

- 分钟级: 5m, 15m, 30m, 60m, 120m, 240m
- 日线级: 1d, 2d

## 使用方法

### 在LLM对话中使用

MCP服务器会自动暴露工具给LLM使用。你可以用自然语言进行查询:

**示例1: 单品种多周期查询**
```
用户: 帮我看一下螺纹钢rb2505在15分钟、30分钟、60分钟的策略信号

LLM会自动调用工具:
- rb2505 15m
- rb2505 30m  
- rb2505 60m
```

**示例2: 多品种查询**
```
用户: 同时查一下rb2501、i2505、hc2501这三个品种的日线信号

LLM会自动调用工具:
- rb2501 1d
- i2505 1d
- hc2501 1d
```

**示例3: 复杂组合查询**
```
用户: 帮我分析一下rb2505的多个周期,包括5分钟、15分钟、30分钟、60分钟和日线

LLM会批量查询5个周期的信号
```

### 工具参数

```typescript
{
  "queries": [
    {
      "symbol": "rb",           // 品种代码
      "contract": "2501",       // 合约代码(4位数字)
      "period": "15m",          // 周期
      "ma_period": 16           // 均线周期(可选,默认16)
    }
  ]
}
```

## 注意事项

1. **后端服务**: 使用前请确保乾坤期货后端服务已启动(端口8000)
2. **API地址**: 如果后端服务在不同地址,请修改`QIANKUN_API_URL`环境变量
3. **批量查询**: 建议单次查询不超过10个组合,以保证响应速度
4. **错误处理**: 单个查询失败不会影响其他查询

## 故障排查

### MCP服务器未连接

1. 检查后端服务是否启动
2. 验证MCP设置文件路径正确
3. 重启VSCode或LLM应用

### 查询失败

1. 检查品种代码是否正确
2. 确认合约代码格式(4位数字)
3. 验证后端API是否可访问
